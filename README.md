# VK Музыка - Прототип "Совместный VK Микс"

Интерактивный продуктовый прототип новой функции для мобильного приложения VK Музыка.

**Демо прототипа (GitHub Pages):** [kazantsev-developer.github.io/vk-music](https://kazantsev-developer.github.io/vk-music/)

## Суть фичи

**"Совместный VK Микс"** - генерация общей бесконечной волны треков для двух пользователей ВКонтакте на основе их музыкальных предпочтений.

### Что реализовано в прототипе:

1. **Точки входа на главном экране:** кнопка "Совместный микс" рядом с "Настроить" и виджет-приглашение под карточкой волны.
2. **Выбор друга:** шторка со списком друзей из ВК и процентом совпадения музыкальных вкусов.
3. **Настройка баланса волны:** ползунок от "Больше моего" через "50/50" к "Больше друга", который в реальном времени перестраивает очередь треков.
4. **Прозрачность рекомендаций и шеринг:** подписи у каждого трека ("Нравится обоим", "Из треков друга", "Из ваших треков"), реальное воспроизведение аудио и кнопка отправки карточки совместимости в ВК.

## Продуктовая гипотеза и метрики

- **Гипотеза:** если дать пользователям возможность в два клика запускать общий микс с другом из ВКонтакте и делиться карточкой совпадения вкусов, друзья начнут чаще приглашать друг друга и регулярнее возвращаться в сервис.
- **Целевые метрики:** возвращаемость на 1-й и 7-й день, дневная и месячная аудитория, среднее время прослушивания музыки на пользователя и количество репостов карточки совпадения в чаты и истории ВК.
- **Контр-метрика:** доля пропусков треков - снижаем риск того, что музыка друга не понравится, за счёт ручного ползунка баланса вкусов.


## Локальный запуск

```bash
npm install
npm run dev
```
