# VK Музыка - Прототип "Совместный VK Микс"

Интерактивный продуктовый прототип новой функции для мобильного приложения VK Музыка.

**Демо прототипа на Vercel тут:** [ссылка]

## Суть фичи

**"Совместный VK Микс"** - генерация общей бесконечной волны треков для двух пользователей ВКонтакте на основе их музыкальных предпочтений.

### Что реализовано в прототипе:

1. **Точки входа на главном экране:** кнопка "Совместный микс" рядом с "Настроить" и виджет-приглашение под плеером.
2. **Выбор друга:** шторка со списком друзей из ВК и процентом совпадения музыкальных вкусов.
3. **Настройка баланса волны:** ползунок от "Больше моего" через "50/50" к "Больше друга", который в реальном времени перестраивает очередь треков.
4. **Прозрачность рекомендаций и шеринг:** подписи у каждого трека ("Нравится обоим", "Из треков друга", "Из ваших треков"), реальное воспроизведение аудио и кнопка отправки карточки совместимости в ВК.

## Продуктовая гипотеза и метрики

- **Гипотеза:** если дать пользователям возможность в два клика запускать общий микс с другом из ВКонтакте и делиться карточкой совпадения вкусов, это создаст виральный цикл приглашений и повысит регулярность возврата в сервис.
- **Целевые метрики:** Retention (D1/D7), DAU/MAU, Time Spent (время прослушивания на пользователя), Shares (отправка карточки мэтча в чаты и истории ВК).
- **Контр-метрика:** Skip Rate (доля пропусков треков) - снижаем риск негатива за счет ручного слайдера баланса вкусов.

## Локальный запуск

